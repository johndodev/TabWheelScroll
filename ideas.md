# Feature Ideas

- **Skip pinned tabs** — option to exclude pinned tabs from the cycle
- **Disable on scrollable elements** — don't trigger tab switch when the cursor is over a scrollable element (e.g. `<textarea>`, overflow div)
- **Disable right-click+wheel or Alt+wheel independently** — let users turn off either trigger
- **Custom modifier key** — choose Ctrl, Shift, or Meta instead of the fixed Alt key (high impact on Mac where Alt conflicts with special characters)
- **Domain blacklist/whitelist** — disable the extension on specific domains (e.g. Google Maps, Figma) where scroll is already used by the app
- **Tab group navigation** — option to cycle only within the active Chrome Tab Group
- **Scroll to next window** — when reaching the last tab, jump to the next browser window
- **Scroll sensitivity** — configure how many scroll ticks before switching tabs
- **Visual HUD** — show a small overlay with the target tab's favicon and title on switch
- **Switch stats** — counter of total tab switches (simple gamification for power users)
