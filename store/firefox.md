# Firefox Add-on Hub — Tab Wheel Scroll

## Summary (250 chars max)

```
Switch browser tabs using the mouse wheel: scroll while holding Alt or right-click. Supports cyclic tab switching. Automatically skips inaccessible tabs (about:, etc.).
```

## Summary FR (250 chars max)

```
Changez d'onglet avec la molette : faites défiler en maintenant Alt ou clic droit. Navigation circulaire prise en charge. Ignore automatiquement les onglets inaccessibles (about:, etc.).
```

## Description FR

```
Tab Wheel Scroll vous permet de naviguer entre les onglets du navigateur avec la molette de la souris — sans cliquer sur la barre d'onglets.

**Comment utiliser**

- Maintenez **Alt** et faites défiler vers le haut/bas pour changer d'onglet  
- ou maintenez le **bouton droit de la souris** et faites défiler vers le haut/bas

Note : votre curseur doit être positionné sur le contenu de la page (pas sur la barre d'onglets).
✓ Fonctionne également avec les molettes horizontales (ex : Logitech MX Master 3).

**Cas où cela ne fonctionne pas**

Pour des raisons de sécurité, les navigateurs limitent les extensions sur certaines pages. Le défilement ignorera :
- Les pages internes (ex : paramètres)
- Les pages du Web Store des extensions
- Les pages de résultats de recherche (ex : Google Search), sauf si vous avez explicitement autorisé l'extension à y accéder dans les paramètres du navigateur

Sur ces onglets, le changement est simplement ignoré.

## Description EN

```
Tab Wheel Scroll lets you navigate between browser tabs using your mouse wheel — no clicking on the tab bar required. 

**How to use** 

- Hold **Alt** and scroll up/down to switch tabs 
- or hold the **right mouse button** and scroll up/down to switch tabs 

Note: Your cursor must be positioned over the web page content (not over the tab bar itself).
✓ Also supports horizontal scroll wheels (e.g., Logitech MX Master 3).  

**Features**

- Cyclic tab switching: wraps around from the last tab to the first (configurable via the extension popup)

**Where it does not work** 

For security reasons, browsers restrict extensions on certain pages. 
The scroll will skip:

- Internal pages (e.g., settings) 
- Add-on Web Store pages 
- Search results (e.g., Google Search) unless you have explicitly allowed the extension to access these pages in your browser settings.

On these pages, the tab is simply skipped.
