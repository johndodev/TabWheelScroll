# Description

```
This plugin lets you navigate between browser tabs using your mouse wheel.

How to use:
-----------
Way 1 : Hold "Alt" and "scroll up/down" to switch tabs
Way 2 : Hold the "right mouse button" and "scroll up/down" to switch tabs

Notes: 
- Your cursor must be positioned over the web page content (not over the tab bar itself). 
- ✓ Also supports horizontal scroll wheels (e.g., Logitech MX Master 3).

Where it does not work
-----------------------
For security reasons, browsers restrict extensions on certain pages. 
The scroll will skip:
- Internal pages (e.g., chrome:// pages, settings, ...)
- Chrome Web Store pages (where you are currently :))
- Search results (e.g., Google Search) unless you have explicitly allowed the extension to access these pages in your browser settings.

On these pages, the tab is simply skipped.
```
